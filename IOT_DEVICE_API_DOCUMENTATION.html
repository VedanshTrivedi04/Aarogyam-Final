1. System & Hardware Architecture

The Aarogyam / MedAdhere IoT Smart Pill Dispenser is an autonomous, sensor-verified circular 4-compartment medication dispenser powered by an ESP32 microcontroller (or Arduino-compatible architecture). It operates in both fully autonomous offline mode (using an onboard DS3231 RTC and local NVS flash memory) and cloud-synchronized online mode via HTTP REST and real-time WebSockets.

Hardware Component Interface / Pins Operational & Physical Function
Stepper Motor (28BYJ-48 + ULN2003) GPIO 13, 14, 27, 26 Drives 360° circular carousel. 1024 half-steps correspond precisely to 90° rotation per compartment.
Servo Lid Gate (SG90 / MG90S) GPIO 25 (PWM) Opens (90°) and closes (0°) the active compartment access aperture.
Ultrasonic Sensor (HC-SR04) Trig: GPIO 19, Echo: GPIO 18 Detects patient hand proximity (≤ 15 cm) to trigger gate opening and record retrieval.
Precision Load Cell (1 kg + HX711) DOUT: GPIO 35, SCK: GPIO 18 Reads sub-gram carousel weight before and after lid closure to verify pill removal.
Real-Time Clock (DS3231) I2C: SDA 21, SCL 22 (0x68) High-precision temperature-compensated RTC for autonomous schedule tracking without WiFi.
OLED Display (SSD1306 128×64) I2C: SDA 21, SCL 22 (0x3C) Renders medicine name, dosage instructions, time slot label, and system status.
DFPlayer Mini MP3 Audio UART2: TX 17, RX 16 Voice audio guidance in Hindi/English (dose reminder, take medicine, taken, missed, unlock).
Hall Effect Sensor GPIO 33 Detects carousel magnet for automatic homing to Compartment 1 reference index.
Buzzer & Indicator LED Buzzer: GPIO 32, LED: GPIO 2 Multi-frequency chimes and visual blinking indicator during active dose windows.

2. Authentication Protocol

All communications between the IoT device and the cloud backend are strictly authenticated:

  • HTTP REST Endpoints: Header X-Device-Key: <DEVICE_API_KEY> (Validated by DeviceAPIKeyAuthentication).
  • WebSocket Channel: Query parameter ?device_key=<DEVICE_API_KEY> (Validated by DeviceKeyAuthMiddleware).

5. Event Catalog & Hardware Action Table

Event Name Trigger Condition Hardware Reaction & Backend Action
DEVICE_BOOT ESP32 power up or reset Performs sensor self-test, homes carousel, requests daily schedule bundle.
DOSE_STARTED RTC slot time match (IST) Rotates stepper to target slot, tare reads load cell baseline, rings buzzer.
HAND_DETECTED Ultrasonic sensor ≤ 15 cm Opens servo lid (90°), displays prompt on OLED, plays audio track.
LID_CLOSED Hand withdrawn from slot Closes servo lid (0°), waits 3s weight stabilization, triggers scale reading.
WEIGHT_READING Post-dose load cell read Backend validates ΔW against expected reduction; marks session taken/partial.
DOSE_TAKEN Intake verified Decrements pill count in DB inventory, plays confirmation chime, notifies caregiver.
DOSE_MISSED 60-min window elapsed Locks gate, triggers caregiver escalation notifications via Twilio & FCM.
LOW_BATTERY Battery level < 15% Logs critical power telemetry, alerts caregiver to plug in USB-C charger.

6. Remote Commands Catalog

Command Name Parameters Physical Hardware Execution
DISPENSE_NOW / TRIGGER_DOSE {"compartment": 1} Immediately rotates stepper to compartment, plays voice prompt, and dispenses medicine.
START_FILL_MODE {"compartment": 1, "medication_name": "Aspirin"} Rotates to slot 1, opens lid, displays medicine name on OLED, prepares scale for refill.
NEXT_COMPARTMENT {"compartment": 2, "medication_name": "Vitamin C"} Closes lid, pauses 500ms, rotates stepper to slot 2, and re-opens lid.
END_FILL_MODE {} Closes lid, chimes 3 times, locks in expected baseline weights, exits fill mode.
READ_FILL_WEIGHT {"medicine_id": "...", "compartment_number": 1} Settles scale for 3 seconds, reads HX711 grams, and posts reading to backend.
GATE_LOCK {} Closes lid immediately, sets locked flag, plays missed dose audio.
GATE_UNLOCK {} Clears locked flag, plays unlock audio, enables normal access.
SYNC_CONFIG {} Re-fetches schedule bundle from cloud backend and refreshes slot times.

8. End-to-End Dispensing Data Flow

[Device Boot / RTC Sync] Device → GET /api/v1/iot/sync/time/ → RTC DS3231 Calibrated Device → GET /api/v1/iot/devices/{id}/config/ → Schedule Bundle Saved in Flash Device ↔ ws://.../ws/iot/device/{id}/ → Bi-Directional Command Channel Active [Autonomous Scheduled Dispensing Cycle] 1. DS3231 RTC hits Slot Time (e.g. 08:00 IST) 2. Device → POST /api/v1/iot/events/ (DOSE_STARTED) 3. Stepper rotates to Compartment 1 (1024 half-steps) 4. HX711 reads carousel baseline weight tare 5. DFPlayer plays Audio Prompt 1 & Buzzer chimes 6. Patient hand approaches (HC-SR04 ≤ 15 cm) → Servo Gate opens (90°) 7. Device → POST /api/v1/iot/events/ (LID_OPENED) 8. Hand withdraws → Servo Gate closes (0°) → POST (LID_CLOSED) 9. Scale settles (3s) → HX711 reads after-dose weight 10. Device → POST /api/v1/iot/events/weight-reading/ 11. Backend verifies ΔW → replies dose_status: "taken" 12. Device plays Confirmation Track 3; Inventory decremented in database
